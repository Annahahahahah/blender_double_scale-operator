# blender_double_scale-operator 
A simple Python operator that doubles the scale of the selected object. 
Простой оператор на Python, который увеличивает выбранный обьект в 2 раза.
# how it works + how to use this
- Install the add‑on via Preferences -> Add‑ons -> Install.
- Select an object and launch the operator from the panel.
- Установить аддон через Preferences -> Add-ons -> Install.
- Выбрать объект и запустить оператор из панели.
